# 全任务自动预算实施计划

目标：用户只选择论文、任务类型和问题，摘要、问答及综述的执行资源由后端分配。实现保持单篇任务现有证据协议和综述分阶段工作流。

1. 先补充策略及提交回归：六类关键行为为规模增长、服务器上限、多语言保守估算、空证据、幂等重放、旧任务兼容；运行并确认新行为尚未实现。
2. 新增 research/task_policy.py，使用实际选定证据及完整提示估算输入，动态计算输出、总 Token 和超时；服务器配置上下文/输出/总量上限。创建时冻结证据与策略，Worker 读取快照，避免执行时证据变化使计划失效。新单篇任务模型超时受 RESEARCH_CALL_TIMEOUT_SECONDS 限制；LLM_TIMEOUT_SECONDS 保留旧任务配置语义，不自动重试、自动续写或保证模型永不截断。
3. 所有新任务忽略有效客户端 budget。真实综述沿用现有策略；模拟任务使用后端确定的两步预算，不调用模型。用冻结的 run_config 标记自动预算，兼容既有 review 工作流及旧版手动任务的请求哈希。
4. 前端删除预算表单和旧预算拷贝，所有提交省略 budget；任务详情保留只读执行上限。中英文提示统一说明自动安排。
5. 更新 API、后端配置及操作手册；运行后端测试、前端构建和离线浏览器检查。不创建数据库迁移，不提交 Git。
