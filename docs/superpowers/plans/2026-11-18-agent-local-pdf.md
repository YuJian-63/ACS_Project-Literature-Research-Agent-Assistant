# Agent 本地 PDF 第 1 阶段实施计划

用户已批准实施。沿用 Agent 研究流程与严格 Task 字段，不实现 TACC 传输或远程作业入口，不提交 Git。保留此前未提交的后端适配。

## 设计

- `apis/pdf.py` 从同一份 PDF 字节提取物理页、目录和原文块；arXiv 包装器继续校验版本，保持原有返回字段。
- `apis/sources.py` 提供 `normalize_source` 与 `SourceReader.from_manifest(input_root)`。只接受清单指定的 `papers/<uuid>.pdf`，核验 UUID、完整 SHA-256、大小和可选页数；拒绝重复、路径逃逸、链接和文件变更。本地来源不回退网络。
- 本地标识为 `local:<uuid>@<sha256>`，块标识追加 `:p<物理页>:c<块序号>`。标题来自授权清单；本地 URL 为空；模型输入和原生结果不包含本地路径。
- baseline 保持 `reader=` 注入方式；支持本地与 arXiv 混合任务、统一论文数量限制及引用去重。缓存命中仍重新核验本地文件。未知或未阅读引用仍拒绝。Task 不增加字段。

## 执行步骤

1. 新增离线测试并观察失败：通用解析、授权来源校验、本地工具链及引用、arXiv 回归。
2. 提取通用解析并实现清单来源解析器；通过对应测试。
3. 适配 baseline 来源授权、缓存、论文数量和引用识别；通过脚本模型测试。
4. 更新 Agent 接口与集成文档；运行完整 Agent 离线测试、相关后端回归及差异检查。

## 重点验收

- 无文本、加密、损坏 PDF 明确报错；chunk 为对应原始物理页的连续原文。
- 清单与文件不符、路径越界、重复 JSON 键、链接、缓存后文件变更均拒绝；错误不泄露路径。
- 本地与 arXiv 的正文和表格引用均可识别；未知引用不能变成成功。
- 所有测试不调用真实模型、搜索、TACC 或数据库。Agent 数据库测试显式关闭。
