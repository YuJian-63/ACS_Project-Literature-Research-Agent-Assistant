## 边界与约束

- 默认供独立 Agent、local 和 TACC 共用；保留原 prepare_context 供显式注入和摘要子调用使用。
- 收尾占用现有主模型步数，继续遵守上下文容量、时限、来源授权和引用校验。
- 不剪裁原文作为完整证据，不改写派生摘要，不移除系统指令、用户输入、工具调用配对或最新原文。
- 投影变化后重新估算，不能套用原始请求前缀的 usage 锚点；继续预留完整输出上限。
- 原文归档仍不能容纳时（例如任务指令、派生摘要或最新阅读本身过大），继续明确返回 context_limit，不能保证任意数量论文均可放入固定窗口。
