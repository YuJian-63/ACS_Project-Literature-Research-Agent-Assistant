# 前端 MVP：研究工作台

用户于 2026-11-11 确认范围：论文库与 PDF 上传、新建摘要/问答/综述任务、任务列表与详情、轮询及错误恢复。沿用 Proposal 中的 React、TypeScript、Vite、Ant Design、Axios、React Router、React Markdown；不做外部搜索、模型配置或虚构指标图表。

## 页面与交互

- `/papers`：分页、标题/文件名搜索、状态筛选、单文件上传、跨页论文选择、PDF 原文件入口；选中的论文可带入新建任务。
- `/tasks/new`：选择论文，填写任务类型、问题和预算；严格按 API 契约校验。相同规范化请求的网络重试复用幂等键，不自动重试 POST；主动重跑是填充旧输入后创建新任务。
- `/tasks`：分页、状态与类型筛选，打开持久化任务详情。
- `/tasks/:taskId`：立即查询，再按上轮完成后 2 秒轮询；不叠加请求，卸载取消。查询失败保留上次状态，不能伪造 failed。增量获取事件，终态停止自动轮询；结果/事件失败可手动重查。
- Markdown 禁用原始 HTML 和远程图片；PDF、引用、比较表仅展示真实接口返回内容。持续明确标注模拟运行，不将 null 统计伪装为 0。

## 视觉与边界

中文、桌面优先且移动端可操作的 Operate/Read 工作台：浅冷灰画布、白色内容面、深蓝导航与蓝色主要操作；信息按论文、输入、执行、结果组织，不使用装饰性指标卡和假数据。采用系统中文无衬线字体与 Ant Design 的可访问组件，保留清晰焦点、文字状态及键盘操作。空状态引导下一步，错误提供明确的重试入口。

默认通过 Vite 同源代理访问本机后端，亦支持配置公开的 API origin。只面向受信本地单用户环境，前端变量不能包含密钥。无真实解析、Agent 或登录系统；不更改后端契约。
