日期：2026-11-21。当前分支：`frontend-dev-v3`。

## 合并原则

采用 main 的统一研究接口、Agent 派发与结果适配实现，保留 v3 的统一页面和独立环境。新建研究仍要求填写问题，参考论文可选（0—20 篇），不恢复摘要、问答、综述三类页面。

## 前端

- 保留新建研究、研究记录和按返回内容显示的研究结果页面。
- 合入研究草稿保留、账号退出清理草稿、提交幂等键和失败重试逻辑。
- 合入外部 arXiv 来源导入：先核对版本、下载与解析，再用本地论文 UUID 打开 PDF；保留引用位置和返回研究的导航。
- 保留 v3 端口 5175、API 代理 8002，以及语言、侧栏、登录广播等独立存储命名。
- 保留登录、搜索、论文库和此前三秒关闭的通知行为；新增通知也使用三秒。
- 补齐 main 前端检查依赖的 UUID 工具和测试脚本；纯模块检查关闭 WebSocket，不启动开发服务。

## 后端与数据库

- `/api/v1/agent-research` 接入 main 的创建、列表、详情、删除、幂等、归属、配额、派发及原生结果处理。
- 恢复其依赖的 Task、TaskPaper、AgentRun、执行状态、结果校验和 Worker 模块。它们是后端内部依赖，旧三类 `/api/v1/tasks` 路由没有挂载到当前应用。
- v3 数据库仍只允许 `literature_v3` / `literature_v3_test_*`；保留连接目标覆盖防护、独立 Cookie、存储目录和 Compose 配置。
- 保留既有 `agent_research` / `research_papers` 数据。统一列表对新旧两种存储合并排序分页，详情和删除兼容已有记录；论文删除同时检查两种引用。
- 保留 `alembic_v3` 迁移链，新增 `v3_0002_agent_execution.py`，只增加执行所需六张表。初始 `v3_0001` 不改写；有执行记录时拒绝直接降级删除表。
- 应用健康检查读取同一条 v3 迁移链，避免误读 main 的旧迁移目录。
- 合入 main 的 Agent 源码更新及后端依赖锁定文件。保留改密成功不退出、旧密码错误返回业务错误的行为。

本次没有启动平台服务、执行实际数据库迁移、修改私有 `.env`、复制账号或论文、删除数据库或存储文件。

## 上游仍缺少的运行文件

本次拉取的 main 已提交后端执行适配器，但没有提交它引用的以下 Agent 文件：

- `agent/run_dispatch.py`
- `agent/agent_io/`
- `agent/tacc_bridge.py`
- `agent/tacc.example.json`

本地执行监督器和部署打包器引用这些文件。因此，接口适配代码已合入，但不能宣称本地/TACC 真实 Agent 已完成可运行对接。需要从这些模块的实现方补齐源文件、配套原文读取模块与测试，再使用独立 Agent Python 环境进行进程往返验收。不能用普通 baseline CLI 输出替代派发结果信封。

历史验收文档描述的是另一环境的结果，不能证明这次检出的源码具备上述文件。保留失败的部署测试，不跳过或伪造通过。
